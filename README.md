# Crolina Store

Next.js App Router + TypeScript + Tailwind CSS storefront for South African customers. Currency: ZAR.

## Setup
1. Use Node.js 20+.
2. Run npm install.
3. Copy .env.example to .env.local and configure Supabase.
4. Run npm run dev.

Supabase project: dbyzwgbdoiepfrgzfcsz (sa-east-1). Database schema and RLS policies have been applied. This repository is a storefront foundation; checkout, payment-proof handling, admin order management, Resend notifications, DNS and production verification remain to be completed before accepting live orders.
